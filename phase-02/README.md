# Фаза 2 (Мета) — переработана после проектной оценки фазы 3

ВНИМАНИЕ: содержимое `phase-02/` — обновлённая версия первоначальной фазы 2. Сохраняет номера T16–T27 и T28–T53, **но** WBS, числовые допущения и оптимальное решение обновлены по более детальной фазе 3. Предыдущее решение следует считать `superseded`.

## Материалы

- `input/model_task_data.json` — 26 задач оценки фазы 3, 3 набора часов и предпочтений, зависимости, компетенции.
- `expert-inputs/expert-1.xlsx` … `expert-3.xlsx` — 3 отдельные анкеты для **26 задач** (трудоёмкость, предпочтение 1–5, компетенции); все исходные числа модельные.
- `calculations/Фаза_2_распределение_по_фазе_3.xlsx` — общее представление WBS, оценок, предпочтений, решения, чувствительности и 12 мета-задач.
- `calculations/MIP_formulation.md` — точная математическая задача и ограничения.
- `calculations/solve_allocation.py`, `allocation_solution.json/.csv`, `sensitivity.csv` — воспроизводимый оптимум (HiGHS, MIP-gap=0).
- `calculations/sync_expert_forms.py`, `apply_solution.py`, `REPRODUCE.md` — путь обновления результата после заполнения анкет.
- `meetings/` — черновики протоколов T16 и T27.
- `report/` — отчёт DOCX/PDF.

## Главные цифры демонстрационной модели

22 индивидуальные + 4 общие задачи = 26 задач фазы 3; 82,5 чел·ч суммарно; У1/У2/У3 — по 27,5 ч. Для сравнения, λ=0 даёт 30,5 / 21,5 / 30,5 ч. Собственная фаза 2 (мета-работы T16–T27) занимает 26,75 плановых чел·ч.
