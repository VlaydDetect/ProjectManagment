# Математическая модель распределения работ фазы 3 (обновлённая фаза 2)

**Статус:** решена на демонстрационных трёх наборах оценок; не подтверждает, что команда проводила опрос.

## Вход и смысл величин

- `I` — 22 индивидуальные задачи T29–T53 без общих T28, T44, T45, T52.
- `P={1,2,3}` — участники.
- `h_i` — медиана трёх оценок трудоёмкости задачи *i*, человеко-часы, не длительность календаря.
- `q_ip ∈ {1,…,5}` — оценка привлекательности задачи *i* для *p*, 5 — наиболее желательная.
- `a_ip ∈ {0,1}` — разрешение назначения с учётом предметной компетенции. Предполагается, что COSMIC/UCP доступны У2/У3, управление публикацией — У1, отчёт — У1/У3. Эти ограничения **гипотетические**, перед итоговым выбором их согласует команда.
- `b_p = 4.5` ч — вклад общих T28, T44, T45, T52 в индивидуальную нагрузку У1–У3.
- `C_p = 32` ч — допустимая учебная нагрузка участника на фазу 3.
- `λ = 3` — выбранная цена 1 часа разброса нагрузки в условных единицах штрафа предпочтения.

## Переменные

`x_ip ∈ {0,1}` — выполнять ли задачу *i* участнику *p*; `Lmax,Lmin ≥ 0` — максимальная и минимальная нагрузка.

```
min Σ(i∈I) Σ(p∈P) h_i·(5−q_ip)·x_ip + λ·(Lmax−Lmin)

∀i∈I:              Σ(p∈P) x_ip = 1
∀i,p, a_ip=0:      x_ip = 0
∀p:                L_p = b_p + Σ(i∈I) h_i·x_ip
∀p:                L_p ≤ 32
∀p:                Lmin ≤ L_p ≤ Lmax
x_ip ∈ {0,1},     Lmin,Lmax ≥ 0
```

Общие задачи **не назначаются одному исполнителю**: каждый присутствует как R, A назначена только одному в RACI. Их нагрузка добавлена к `b_p`.

## Решатель и результат

`python phase-02/calculations/solve_allocation.py` использует `scipy.optimize.milp` (HiGHS). Применена целочисленная модель; статус `0`, `MIP gap=0` — **доказанная оптимальность при исходных допущениях**.

| Величина | Итог |
|---|---:|
| Индивидуальных задач | 22 |
| Совместных задач | 4 |
| Общая нагрузка | 82,5 чел·ч |
| У1 / У2 / У3 | 27,5 / 27,5 / 27,5 ч |
| Штраф предпочтений | 6 условных ч×баллов |
| Разброс нагрузки | 0 ч |
| Значение цели при λ=3 | 6 |

При `λ=0` достигается штраф предпочтений 0, но нагрузка 30,5 / 21,5 / 30,5 ч (разброс 9 ч). При `λ≥1` выбранная демонстрационная модель имеет равномерное распределение; подробности в `sensitivity.csv`.

**Важное различие:** 82,5 чел·ч — время **проведения учебного оценивания** фазы 3. Разработка приложения CampusEvents по экспертной модели оценивается отдельно в **490 чел·ч**. Смешивать эти показатели нельзя.

## Ограничения модели

1. Компетенции, предпочтения и часы — демонстрационные допущения, а не доказанные ответы трёх человек.
2. Фазы 2–3 включают календарный план, но MILP **не решает задачу календарного расписания с предшествованиями**: он решает только назначение работ.
3. При изменении экспертных анкет нужно синхронизировать оценки, заново запустить решатель, утвердить RACI и переписать отчёт.
