# Повторение расчёта

Для работы требуется Python 3.11+, `scipy`, `numpy`, `artifact_tool` (последний — для чтения и изменения XLSX; в режиме только оптимизации не нужен).

Из корня пакета `phase23_project`:

```bash
python phase-02/calculations/sync_expert_forms.py
python phase-02/calculations/solve_allocation.py
python phase-02/calculations/apply_solution.py
```

1. `sync_expert_forms.py` считывает три индивидуальных файла фазы 2 и три индивидуальных файла фазы 3, проверяет ID, числовые диапазоны и переносит значения в общие Excel и JSON. Он **не может проверить подлинность экспертного опроса или факт консенсуса**.
2. `solve_allocation.py` заново решает задачу назначений MILP, формирует решение JSON, CSV и чувствительность по λ. Меняйте параметры `--fairness` и `--capacity` явно. Если модель неразрешима (например, все эксперты запретили квалификацию), исправьте допущения, не обходите ограничения.
3. `apply_solution.py` обновляет плановые назначения в Excel фазы 2 и в **локальных** RACI/журнале. Фактические поля не изменяются.
4. Сверьте новые числа, перепишите выводы и приложите протокол реального согласования.

Файлы `phase-03/measurements/Фаза_3_оценка_CampusEvents.xlsx` и `phase-02/calculations/Фаза_2_распределение_по_фазе_3.xlsx` содержат собственные формулы. После изменения вводных чисел Excel пересчитает зависимые клетки. Для изменений COSMIC и UCP надо править функциональные движения и факторы непосредственно в соответствующей книге.
