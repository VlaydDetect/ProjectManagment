## Контрольные показатели модели

| Метод | Результат |
|---|---:|
| COSMIC | 47 CFP |
| UCP | UAW=6, UUCW=110, TCF=0,96, ECF=0,95; UCP=105,792 |
| UCP × 20 чел·ч/UCP | 2115,84 чел·ч (**откалиброванный сценарий**) |
| Экспертный базовый объём | 392 чел·ч (сумма медиан 12 UC) |
| Экспертный базовый +25% общих работ | 490 чел·ч |
| Предположенная команда и ориентир | 3 человека (frontend/backend/QA-UX), около 7 недель при 70% загрузки и 20% резерве по сроку |

COSMIC и UCP нельзя автоматически сравнивать как одни и те же единицы. Ни COSMIC, ни UCP не определяют фактическую скорость команды без исторической калибровки. Модельные оценки участников следует подтвердить и получить подписанный реальный консенсус на T45.

Для сокращения объёма предложено перенести UC-07 и UC-11 (54 чел·ч по UC, 67,5 чел·ч с пропорциональной долей общих работ). Тогда останется 10 UC — минимально допустимое для предмета число, но это **сценарий сокращения**, а исходные измерения сделаны для 12.
