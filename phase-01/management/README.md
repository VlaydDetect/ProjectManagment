# Управленческие документы — основная версия для всех фаз

**`RACI_сквозная.xlsx`** — единственная актуальная матрица ответственности на весь учебный проект. Текущие записи T01–T15 повторяют исходную плановую RACI. Роли A/R, R, C, I; каждая задача обязана иметь **ровно одну** A. На листе «RACI» есть автоматическая проверка. Листы «Регламент» и «История изменений» описывают обновление и версии.

**`Журнал_задач.xlsx`** — единственный сквозной журнал задач и времени. По каждой задаче хранит ID, фазу, владельца (A), период **план/факт**, часы каждого участника **план/факт**, итоговые человеко-часы, статус и артефакт. На листе «Сводка» рассчитан текущий план 29,3 чел·ч. Фактические даты и часы намеренно пустые; статус каждой задачи — «План».

Листы «RACI» и «Задачи» внутри общей книги расчётов по выбору концепции — **снимок исходного плана**. Именно эти два файла `management/` необходимо актуализировать после каждой фазы. При подготовке итогового отчёта делайте в нём снимок текущей RACI и статистики задач.
