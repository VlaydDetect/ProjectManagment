# Expert inputs — три индивидуальные анкеты

У каждого эксперта **отдельная** Excel-книга с листами `Инструкция`, `TOPSIS_оценки` (25 строк), `МАИ_сравнения` (40 строк).

Синие ячейки `E5:E29` и `E5:E44` содержат **демонстрационные** числа из исходной книги.

## Копирование в `calculations/Фаза_1_расчеты_TOPSIS_МАИ.xlsx`

| Кто | `TOPSIS_оценки!E5:E29` | `МАИ_сравнения!E5:E44` |
|---|---|---|
| expert-1 | `Оценки!E5:E29` | `МАИ суждения!E5:E44` |
| expert-2 | `Оценки!F5:F29` | `МАИ суждения!F5:F44` |
| expert-3 | `Оценки!G5:G29` | `МАИ суждения!G5:G44` |

Вставка → **Только значения**, с сохранением позиций строк и всех формул вычисления в исходной книге.
